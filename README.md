# Supply Chain Fulfillment & Logistics Performance Analysis

## Project Overview

This project analyzes supply chain delivery performance using the DataCo
Supply Chain Dataset. The analysis focuses on delivery delays and examines
performance across regions, shipping modes, product categories, and customer
segments.

## Business Problem

Late deliveries can affect customer satisfaction, operational efficiency,
and supply chain reliability. This project uses SQL, Python, and Power BI
to analyze delivery performance and create an interactive executive
dashboard.

## Objectives

- Measure overall delivery performance.
- Calculate on-time and late delivery rates.
- Compare actual and scheduled shipping days.
- Analyze delivery performance by region.
- Compare different shipping modes.
- Identify product categories with high late-delivery rates.
- Analyze delivery performance across customer segments.
